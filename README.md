# 4UrLoev

E-commerce website for DIY products and personalized gifts.

## Features

- Product catalog, cart, and checkout flow
- Product customization with a canvas editor (fabric.js)
- 3D visuals with TresJS (three.js)
- Admin panel for orders, products, and users
- Supabase authentication and data
- Sitemap generation and image optimization

## Tech Stack

- Nuxt 4, Vue 3, TypeScript
- Supabase (auth and database)
- Tailwind CSS, Pinia
- fabric.js, TresJS, embla-carousel

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Build for production:

```bash
npm run build
npm run preview
```
